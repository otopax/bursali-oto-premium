# Executive Dashboard (Yönetici Paneli Standartları)

C-Level (Yöneticiler) için platformun bir bakışta genel sağlığını ve başarısını özetleyen veri matrisi. Operasyonel KPI'ların (Mühendisler için) özetidir.

## İzlenecek Kilit Metrikler
1. **Uptime (Erişilebilirlik):** Son 30 gün (%99.9x)
2. **Aktif Kullanıcı:** Günlük tekil (Unique) ziyaretçi.
3. **Günlük Randevu:** Chatbot + Form üzerinden kesinleşen randevu sayısı.
4. **AI Maliyeti:** Toplam harcanan Token / Aylık Fatura karşılığı (USD).
5. **AI Doğruluk Oranı (Faithfulness):** %95+
6. **Gelir (Revenue):** Faturalanan toplam tutar (ERP entegrasyonundan).
7. **Kritik Olay Sayısı (Incident):** O ay yaşanan P1/P2 seviye çökme sayısı (Hedef: 0).
8. **Güvenlik Olayları:** Engellenen Prompt Injection veya WAF atak sayısı.
