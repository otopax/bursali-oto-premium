# Platform Maturity Model

Organizasyonumuzun yazılım, operasyon ve yapay zeka alanlarındaki olgunluk seviyelerini ve hedeflerini gösteren matris.

| Capability (Yetenek) | Current (Mevcut) | Target (Hedef) | Owner (Sorumlu Ekip) |
| :--- | :--- | :--- | :--- |
| **AI (Yapay Zeka)** | Level 3 (RAG + Cache) | Level 5 (Multi-Agent, Auto-fix) | AI Team |
| **DevOps / CI-CD** | Level 4 (Auto Deploy) | Level 5 (Zero-Downtime, Canary) | Platform Eng |
| **Security** | Level 3 (WAF, Prompt Guard) | Level 5 (SOC2, Auto Audit) | Security |
| **Observability** | Level 4 (Sentry + OTEL) | Level 5 (Predictive Alerts) | SRE |
| **Compliance** | Level 3 (GDPR Anonymization)| Level 5 (Continuous Compliance)| Compliance |
