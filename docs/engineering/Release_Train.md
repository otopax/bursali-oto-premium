# Release Train (Sürüm Treni)

Yazılımın canlı ortama alınma politikası.

1. **Weekly Patch (Haftalık Yama):** Çarşamba sabahları (Trafiğin en az olduğu saatler). Küçük hata düzeltmeleri (Bugfixes).
2. **Monthly Minor (Aylık Sürüm):** Ayın ilk Pazartesi günü. Yeni özellikler (Örn: VIP Garaj Modülü).
3. **Quarterly Major (Çeyreklik Majör):** Yılda 4 kez. Büyük altyapı değişiklikleri (Örn: Next.js 16'ya geçiş, Veritabanı cluster değişimi).
4. **Emergency Hotfix:** Acil durum (Örn: Ödeme sistemi çöktü). Kurallar esnetilerek anında (OAC ve Load Test atlanarak) canlıya alınır.
