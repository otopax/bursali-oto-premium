# Documentation Lifecycle (Doküman Yaşam Döngüsü)

Platform dokümanlarının (ADR, Runbook, Platform Mimarisi) her zaman güncel kalmasını sağlayan yaşam döngüsü kuralları.

1. **Draft (Taslak):** Yeni teknoloji veya süreç PR (Pull Request) olarak açılır.
2. **Review (İnceleme):** İlgili domain sahipleri tarafından incelenir.
3. **Approved (Onaylı):** Merge edilir.
4. **Published (Yayınlandı):** Ana dokümantasyonda (docs/) yer alır.
5. **Deprecated (Kullanımdan Kalktı):** Teknoloji değiştiğinde (Örn: Railway'den AWS'ye geçiş) eski doküman [DEPRECATED] olarak işaretlenir.
6. **Archived (Arşiv):** Bir sonraki majör sürümde tamamen silinir.
